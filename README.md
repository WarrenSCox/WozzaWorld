# WozzaWorld v0.4

Map-first travel app prototype.

## v0.4 visual direction
- WozzaWorld blue sky background (`#02BCD6`)
- Gentle animated white clouds
- Minimal map screen: no heading, refresh control, map instructions or separate colour legend
- Map status colours: visited `#BCDA00`, visiting `#FFD868`, everything else grey
- Status colour key is built into the underline beneath each count
- "Add to mobile" hides when the PWA is running as an installed app, and after a successful install prompt
- Bucket list terminology throughout
- Equal Earth world map retained
- Flat-file structure for quick GitHub uploads

Upload every file in this ZIP directly to the repository root.
